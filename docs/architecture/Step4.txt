You are building Part 4 of an enterprise automotive DMS/CRM system: the Accounting & Financial Suite.

- Tech Stack: React 18 + TypeScript + Vite + Tailwind CSS (frontend), Express.js + TypeScript + Prisma ORM (backend), PostgreSQL

- Database has: Tenant, User, Customer, Vehicle, Deal, JournalEntry, GLAccount, SystemSetting tables

Build a complete financial management system following GAAP accounting principles. This includes dashboards, financial statements (P&L, Balance Sheet, Cash Flow), journal entry system with auto-generation from deals, chart of accounts, payroll with commission tracking, and tax reports.

- Total Credits: $XX,XXX.XX

- Cancel

VOID JOURNAL ENTRY:

- Show confirmation modal
- Explain: "This will create a reversing entry and mark this entry as void"
- On confirm:
  * Create new entry with all debits/credits reversed
  * Link new entry to original
  * Mark original as "Void"
  * Set void date and user

DUPLICATE ENTRY:
- Copies all line items to new draft entry
- Updates date to today
- Clears entry number (assigned on post)
- Opens in edit modal

AUTO-GENERATED ENTRIES:
When deal is closed, auto-create journal entry:

Example for $35,000 vehicle sale (COGS $28,000, trade-in $8,000):

Entry Description: "Vehicle Sale - Deal #D-2025-4567"
Lines:
DR  Cash                    $27,000  (Cash down)
DR  Accounts Receivable     $8,000   (Financed amount)
    CR  Vehicle Inventory            $28,000
    CR  Sales Revenue                $35,000

DR  Vehicle Inventory       $8,000   (Trade-in)
    CR  Customer Trade Credit        $8,000

DR  Cost of Goods Sold      $28,000
    CR  Vehicle Inventory            $28,000

DR  Commission Expense      $1,200
    CR  Commission Payable           $1,200

F&I Products:
DR  Cash                    $2,500
    CR  F&I Revenue                  $2,500

Link entry to deal record so it appears on deal detail page

POST   /api/accounting/journal-entries/:id/post (post draft entry)

Database Schema:
model JournalEntry {
  id          String   @id @default(uuid())
  tenantId    String
  entryNumber String   // JE-2025-1234
  date        DateTime
  description String
  type        String   // MANUAL, AUTO_DEAL, AUTO_PAYMENT, ADJUSTMENT, RECURRING
  status      String   // DRAFT, POSTED, VOID
  memo        String?
  totalDebit  Decimal
  totalCredit Decimal
  dealId      String?  // Link to deal if auto-generated
  voidedAt    DateTime?
  voidedBy    String?
  voidedByEntry String? // ID of reversing entry
  isRecurring Boolean @default(false)
  recurringFrequency String? // MONTHLY, QUARTERLY, YEARLY
  recurringEndDate DateTime?
  createdBy   String
  createdAt   DateTime @default(now())
  updatedAt   DateTime @updatedAt

```typescript
import * as XLSX from 'xlsx';

export const exportPLToExcel = (data: PLData, period: DateRange) => {
  const wb = XLSX.utils.book_new();
  
  const wsData = [
    ['Profit & Loss Statement'],
    [`For the period ${period.start} to ${period.end}`],
    [],
    ['REVENUE'],
    ['Vehicle Sales Revenue', data.vehicleSales],
    ['F&I Revenue', data.fiRevenue],
    ['Service Revenue', data.serviceRevenue],
    ['Total Revenue', data.totalRevenue],
    [],
    ['COST OF SALES'],
    // ... continue building data array
  ];
  
  const ws = XLSX.utils.aoa_to_sheet(wsData);
  
  // Format currency columns
  const range = XLSX.utils.decode_range(ws['!ref']!);
  for (let R = range.s.r; R <= range.e.r; ++R) {
    const cellAddress = XLSX.utils.encode_cell({ r: R, c: 1 });
    if (ws[cellAddress] && typeof ws[cellAddress].v === 'number') {
      ws[cellAddress].z = '$#,##0.00';
    }
  }
  
  XLSX.utils.book_append_sheet(wb, ws, 'P&L');
  XLSX.writeFile(wb, `PL_Statement_${period.start}_${period.end}.xlsx`);
};
```

Implement business logic for all accounting operations:

Key functions:

1. generatePLStatement(tenantId, startDate, endDate, comparisonPeriod?)

- Query all journal entries in period
- Aggregate by account type and category
- Calculate totals, subtotals, percentages
- If comparison enabled, query comparison period and calculate variance

1. generateBalanceSheet(tenantId, date, comparisonDate?)

- Calculate running balances for all balance sheet accounts as of date
- Group by account type (Asset, Liability, Equity)
- Calculate totals and ratios

1. generateCashFlow(tenantId, startDate, endDate, method)

- If indirect: start with net income, adjust for non-cash items
- Calculate changes in working capital accounts
- Separate into Operating, Investing, Financing activities

1. autoGenerateJournalEntry(deal)

- When deal is closed, automatically create JE
- Debit/credit appropriate accounts based on deal structure
- Handle vehicle sale, trade-in, F&I products, commissions
- Link JE to deal

1. calculatePayroll(tenantId, startDate, endDate)

- Get all employees
- Calculate base pay (salary or hourly)
- Calculate commissions from deals closed in period
- Apply bonuses, spiffs
- Calculate deductions (taxes, insurance, 401k)
- Return gross and net pay for each employee

1. importStandardCOA(tenantId)

- Create standard automotive chart of accounts
- Check if accounts already exist (prevent duplicates)
- Return success/failure for each account

const calculateCommission = (deal: Deal) => {
const frontGross = deal.sellingPrice - deal.vehicleCost;
const backGross = deal.fiProducts * 0.5; // Assume 50% margin on F&I

// Tiered commission on front gross
let frontCommission = 0;
if (frontGross <= 1000) {
frontCommission = frontGross * 0.03;
} else if (frontGross <= 2000) {
frontCommission = 30 + (frontGross - 1000) * 0.04;
} else {
frontCommission = 30 + 40 + (frontGross - 2000) * 0.05;
}

// Flat commission on back gross
const backCommission = backGross * 0.05;

return frontCommission + backCommission;
};
