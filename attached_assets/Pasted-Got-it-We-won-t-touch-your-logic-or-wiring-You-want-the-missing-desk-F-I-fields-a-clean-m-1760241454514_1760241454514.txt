3) Totals Panel (right rail — always visible)

Cards (compact):
	•	Front-End = sale_price_cents – vehicle_cost_cents – pack_cents + holdback_cents – discount_cents + (rebates_taxable ? 0 : – rebates_cents)
	•	Back-End = Σ(products.profit) + reserve_amount_cents
	•	Total Gross = front + back
	•	Tax = apply jurisdiction to taxable base:

taxable_vehicle = sale_price – (trade_tax_credit ? trade_allowance : 0)
taxable_fees = Σ(fee.amount where fee.taxable)
taxable_products = Σ(product.retail where product.taxable)
taxable_rebates = (rebates_taxable ? rebates : 0)
tax = (taxable_vehicle + taxable_fees + taxable_products - taxable_rebates) * rate


	•	Out-The-Door (OTD) = sale_price + fees + products + tax – trade_allowance – cash_down

6) Tiny UI Snippets (safe to paste)

Compact money cell (right-aligned, accounting style)

export function Money({cents}:{cents?:number}) {
  if (cents == null) return <>—</>;
  const neg = cents < 0;
  const val = (Math.abs(cents)/100).toLocaleString(undefined,{minimumFractionDigits:2});
  return <span style={{fontVariantNumeric:'tabular-nums', textAlign:'right', display:'inline-block', minWidth:96}}>
    {neg ? `(${val})` : val}
  </span>;
}
